## Issues found and fixed

- **DB-6:** keys of internal-choice alternatives were stored in the student-safe `questions.body`. No API had served them. Fixed in 621f6dc with a deep-scan regression test over every real release.
- Redis KV expired values on Redis time while tests use an injected clock (CI-only failure). Fixed with clock-driven expiry and a KV contract test on memory, ioredis-mock and real Redis.
- The catalog seed skipped the 30 class-default blueprints (fixed 053d4ef, 359 load).
- A Tailwind token in platform code leaked a class into the marketing CSS (found by the flag-off CSS check in M3/M4; fixed 268608f).

## Open at the end of M2
