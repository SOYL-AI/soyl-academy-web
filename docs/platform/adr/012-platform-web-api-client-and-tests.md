# ADR-012: Typed API client generation and platform web test tooling

- **Status:** Proposed (web-platform M1; for Lead approval at integration)
- **Date:** 2026-10-27
- **Author:** web-platform
- **Related:** ADR-001 (consequence: the API client must stay dependency-free), ADR-005, ADR-009; ARCHITECTURE §3.2
  ("typed API client generated from the API's OpenAPI spec into `platform/shared/api-client`"); GEN-5

## Context

Platform pages need a typed client for `platform/api/openapi.json`. Anything Next.js pages import must resolve in
the root build (ADR-001 §9), and `platform/shared` may depend on nothing but zod (D-006). The web app also needs
unit tests (proxy header logic, guest storage, return-to) and Playwright flows against the real local API.

## Options

| Need | Chosen | Alternatives |
|---|---|---|
| Types from OpenAPI | **openapi-typescript 7.13.0** (MIT, Feb 2026), devDependency of `@soyl/shared` in the `platform/` workspace | openapi-fetch (runtime dependency in the root, not needed); orval / openapi-generator (generate runtime code, heavier); hand-written types (drift) |
| Runtime client | **own 150-line fetch wrapper** typed by the generated `paths` | openapi-fetch: a new root runtime dependency for little gain |
| Unit tests | the root vitest 4.1.12 already added by ADR-009, new config `components/platform/vitest.config.mts` | a second test runner |
| E2E | `@playwright/test` + `@axe-core/playwright` already in `@soyl/e2e` | — |

## Decision

- `platform/shared/api-client/schema.gen.ts` is generated by `npm run generate:api-client -w @soyl/shared`
  (from `platform/`). It contains types only. `platform/shared/api-client/index.ts` is the fetch wrapper:
  same-origin credentials, JSON bodies, problem+json → `ApiError` with the stable `code` and `retryAfterSeconds`.
  A test (`api-client.test.ts`, part of `npm test` in `platform/`) regenerates the schema into a temp file and
  fails if the committed file is stale.
- `openapi-typescript` is a **dev** dependency in the `platform/` workspace only. The root `package.json` and
  lockfile get no new dependency. `platform/` `npm audit` shows only the 4 pre-existing moderate advisories
  (drizzle-kit's esbuild), none from this package.
- Root script (additive): `"test:platform-web": "vitest run --config components/platform/vitest.config.mts"`.
- `@soyl/e2e` script: `"test:platform-web": "node tests/platform/web/run.mjs"`: builds the web with the flag ON,
  starts the API dev runner (embedded Postgres, mock SMS/email/consent/Google OIDC) on separate ports and
  `next start`, runs the flows; then builds with the flag OFF and checks every platform route is a 404. It leaves
  `.next` in the flag-off state so the marketing regression can follow.
- `platform/e2e/tests/platform/web/flag-off-html.mjs`: base-vs-HEAD flag-off build comparison of every marketing
  page (HTML, CSS bytes, hydrated DOM, text endpoints).

## Consequences

- Regenerate the client whenever `platform/api/openapi.json` changes; the drift test catches a forgotten step.
- The client bundle has no zod: guest-progress validation is hand-written (`components/platform/lib/guest-storage.ts`)
  and unit-tested against the API's zod contract.
