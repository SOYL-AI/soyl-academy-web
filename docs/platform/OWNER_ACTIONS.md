# Owner actions

Things only the owner can do (accounts, credentials, payments, DNS, legal). Until each is done the platform runs against the stand-in listed, and all tests stay green against that stand-in. When an item is done, tell the Lead; it switches to the real service and reruns the affected gates.

**Never paste secrets into chat or git.** Put them where each item says (Azure Key Vault for API/worker secrets, Vercel project settings for web values, GitHub repository secrets for CI).
